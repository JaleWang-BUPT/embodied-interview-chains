# 卷二 · 强化学习与运动控制 · 追问链

> 具身智能面试追问链题库 · 第二卷
> 题源：公开问题、复盘与历史题单；证据级别和访问差异见题源记录
> 本卷 **16 条链 · 71 个问答节点**
> 难度分布：L1 **2** · L2 **10** · L3 **4**

**使用方式**：题目默认折叠，先自己答一遍主问，再点开对照；然后**合上，从主问开始把整条追问链讲一遍**——本卷练的是"扛得住往下钻"。链条以学习主题组织；历史自记原题与当前可核验正文分开，不将最长链冒称原场次连续提问。

**本卷追问模式**（编者对已收录主题的归纳，不代表公司固定考法）：
1. **公式 → 合法性 → 缺陷 → 补救 → 场景选型**：策略梯度链、GAE 链的标准路径——写得出公式只算入场，可进一步检查"为什么能这么推、有什么毛病"
2. **概念 → 参数 → "这个数怎么定的"**：λ、Q/R、域随机化范围、窗口大小——用数值依据检验概念，GAE 链直接当场算
3. **给症状、定根因、再要方案**：policy loss 震荡 value loss 平稳、仿真完美真机震荡——排障题按信息增益排序作答
4. **方案 → 备择对比 → "为什么不用现成的"**：臂角法 vs Pinocchio/KDL、LADRC vs PID、qpOASES vs OSQP
5. **结果 → 怎么验证**：辨识后检查"新轨迹上怎么验证"、用具体参数追溯个人工作——卷五"真实性核验"在运控方向的高发形态

<summary><span class="lv lv-l2">L2</span> <span class="freq">〔推断·历史题单待核〕</span> <b>C01</b> · 写出策略梯度公式。为什么能对期望求导？</summary>

**答**〔推断·工程作答〕：以有限时域折扣目标 $J=\mathbb E[\sum_t\gamma^t r_t]$ 为例，令 $G_t=\sum_{k=t}^{T-1}\gamma^{k-t}r_k$，则 $\nabla J=\mathbb E[\sum_t\gamma^t\nabla\log\pi_\theta(a_t|s_t)G_t]$。环境转移不依赖策略参数，利用log导数与因果性推导；还需可微、支撑与交换求导/积分等条件。也可把折扣吸收到访问分布，必须说明约定。

**追问 1**〔推断〕：这样估计方差大怎么办？
**答**〔推断·工程作答〕：可用reward-to-go、状态baseline、优势估计、较大批量等方法。GAE通过权衡TD估计的偏差与方差降低噪声，但效果取决于critic误差和采样；不保证任何设置都降方差。

**追问 2**〔推断〕：baseline 为什么降方差、会不会引入偏差？
**答**〔推断·工程作答〕：对给定状态，固定且不依赖所采动作的 $b(s)$ 满足 $\mathbb E_{a\sim\pi}[\nabla\log\pi(a|s)b(s)]=0$，所以减去它不改期望。合适的baseline能降方差，任意baseline不保证；同批拟合或动作相关控制变量需额外分析。

**追问 3**〔推断〕：baseline 有哪些类型？
**答**〔推断·工程作答〕：可用常数、状态价值函数或其他状态函数。方差最优baseline通常还与score范数加权有关，不必恰等于V(s)。实践常用critic并将计算好的优势在actor更新时视为常量。

**追问 4**〔推断〕：机械臂抓取任务用哪个？
**答**〔推断·工程作答〕：先看动作空间、数据成本、奖励稀疏程度与安全约束。可用PPO+critic、离策略方法或演示初始化等；不存在抓取任务唯一正确算法。说明自己选型依据与对照实验，不把教学默认配置当工程定律。

**易错**：把baseline无偏与任意baseline都降方差混为一谈；折扣公式不说采样/回报约定。

**实录**：[卷二题源 C01](https://github.com/JaleWang-BUPT/embodied-interview-chains/blob/main/research/sources-vol2.md#c01)。历史题单无独立原文快照，全链保守按推断练习，不认领公司或实录频次。

<summary><span class="lv lv-l1">L1</span> <span class="freq">〔实录主题+推断〕</span> <b>C02</b> · PPO 的原理？它是 on-policy 还是 off-policy？</summary>

**答**〔推断·工程作答〕：PPO通常采集当前策略rollout，固定旧log概率与优势，再多轮优化clip surrogate。$r_t=\exp(\log\pi_\theta-\log\pi_{\rm old})$，最大化 $\mathbb E[\min(r_t\hat A_t,\mathrm{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t)]$。它通常归类on-policy；有限批次复用不等于任意历史replay。Clip限制部分目标收益，不是硬trust-region或安全保证。

**追问 1**〔推断〕：重要性采样是什么、为什么用？
**答**〔推断·工程作答〕：概率比修正给定状态下动作分布的变化；多轮更新后新旧策略不同，因此用旧样本构造surrogate。单步ratio并不完整校正状态访问分布，clip也引入偏差；需监控KL、ratio与更新幅度。

**追问 2**〔推断〕：Loss 由什么组成？
**答**〔推断·工程作答〕：按最小化约定可写 $L=-L^{clip}+c_vL_V-\beta H$：负actor目标、价值误差、负熵奖励。系数与实现有关；若改成最大化，符号须同时翻转。不能不说优化方向就把三项都加正号。

**追问 3**〔推断〕：能否用总 loss 更新两个网络？
**答**〔推断·工程作答〕：可以相加，但须明确共享参数、计算图与符号。独立actor/critic时分别优化较易检查；合并也可让各项只流向应更新的参数。old logp、已计算advantage和value target通常detach，避免不期望的梯度。

**易错**：把clip当硬约束或把actor/value/熵的优化符号写反。

**实录**：[卷二题源 C02](https://github.com/JaleWang-BUPT/embodied-interview-chains/blob/main/research/sources-vol2.md#c02)。仅保留记录中可追溯的主题锚点；扩展、重排和工程作答均标推断，不报整链频次。
</details>

<summary><span class="lv lv-l3">L3</span> <span class="freq">〔推断·历史题单待核〕</span> <b>C03</b> · GAE 里 λ=0.95 时，第 10 步 TD 残差的权重是多少？（当场算）</summary>

**答**〔推断·工程作答〕：GAE为 $\hat A_t=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}$。若“第10步”指l=9，则权重为 $(\gamma\lambda)^9$；λ=.95且γ=1时约.630，γ=.99时约.576。若题目按l=10编号，指数应为10，先澄清计数；有限rollout还要处理终止与截断。

**追问 1**〔推断〕：灵巧手要在最后 1 秒做精确控制，λ=0.95 合理吗？
**答**〔推断·工程作答〕：不能仅凭“最后1秒”判断。λ控制TD残差组合的偏差/方差，不是控制带宽或固定信用窗口；其有效时间尺度还依赖步长与γ。要看奖励延迟、critic误差、终止处理和消融结果。

**追问 2**〔推断〕：怎么调整？
**答**〔推断·工程作答〕：先核对动作/奖励采样间隔、稀疏性与critic精度，再比较多个λ的回报、末段误差及优势方差；必要时改奖励或课程。调小λ更依赖bootstrap，可能增偏差；不要用一句“末段精控所以调小”替代证据。

**易错**：把λ当成以秒计的控制窗口，或不问步编号就直接写指数。

**实录**：[卷二题源 C03](https://github.com/JaleWang-BUPT/embodied-interview-chains/blob/main/research/sources-vol2.md#c03)。本轮未独立复现具体原题，仅保留历史题单主题，全链推断，不认领公司或实录频次。

<summary><span class="lv lv-l2">L2</span> <span class="freq">〔推断·历史题单待核〕</span> <b>C04</b> · PPO 训四足，policy loss 震荡剧烈但 value loss 稳定下降，可能是什么原因？</summary>

**答**〔推断·工程作答〕：value loss下降不能证明critic健康，也不能仅据policy loss波动判定策略退化；PPO的surrogate跨批次不直接可比。先看真实回报/成功率、目标尺度和explained variance，再查优势分布、KL/clip fraction、熵、梯度与课程变化。学习率、更新轮数、奖励尺度和价值偏差都可能导致症状，逐项给证据后再调参。

**追问 1**〔推断〕：为什么 value loss 平稳不能说明训练没问题？
**答**〔推断·工程作答〕：critic可能只拟合了错误或变化的return target，损失缩小也可能来自尺度变化；它的误差仍会污染优势。联合检查bootstrap/终止处理、价值校准和实际回报，不能把两条loss曲线当充分诊断。

**易错**：只凭loss曲线判定critic健康或策略失效，忽视回报与目标尺度。

<summary><span class="lv lv-l2">L2</span> <span class="freq">〔推断·历史题单待核〕</span> <b>C05</b> · 你的 reward 是怎么设计的？有哪些项？</summary>

**答**〔推断·工程作答〕：reward是即时信号，return是所选折扣下的累计目标。按任务成功/进度、约束与代价、动作变化及可能的运动先验分组，每项写单位、时间尺度和终止语义。先建立可测成功判据，再逐项加入并观察行为与贡献。所有额外塑形都有可能改变目标，不能只靠奖励曲线宣布任务解决。

**追问 1**〔推断〕：出现过 reward hacking 吗？怎么解决？
**答**〔推断·工程作答〕：先保留行为证据和触发条件，再修成功/终止判据或有漏洞的奖励。Potential shaping在相应假设下用 $\gamma\Phi(s')-\Phi(s)$ 保持最优策略，有限时域终止势等条件也要处理；任意进度奖励并无此保证。

**追问 2**〔推断〕：各项权重怎么调？
**答**〔推断·工程作答〕：统一时间尺度与典型量级，记录每项分布和对总回报/梯度的贡献；用消融和受控扫描检查任务成功与约束违反。权重取值须随任务与实现验证，不以某次经验系数直接迁移。

**追问 3**〔推断〕：AMP 做过吗？自己实现的还是用开源的？
**答**〔推断·工程作答〕：AMP用运动状态或状态转移区分参考运动与策略运动，据此形成风格奖励，再与任务目标结合；不是只判别动作向量。说明参考数据、特征、判别器训练与稳定化；自己没实现就讲复用和验证边界。

**易错**：把状态转移判别说成动作向量判别；任意进度奖励冒称不改变最优策略。

<summary><span class="lv lv-l2">L2</span> <span class="freq">〔实录主题+推断〕</span> <b>C06</b> · sim2real 的 gap 从哪来？怎么定位主要的性能损失？</summary>

**答**〔推断·工程作答〕：从动力学/接触、执行器、传感与观测、控制时序四层找差异。记录真机输入输出和时间戳，用已知输入回放、参数辨识、残差分析与消融隔离原因。真机闭环轨迹与仿真不同不唯一证明某个参数错；测量、控制接口或未建模接触也可能造成差异。

**追问 1**〔推断〕：域随机化随机哪些参数？范围怎么定？
**答**〔推断·工程作答〕：可考虑质量/惯量、摩擦、增益、执行延迟、观测噪声和初始状态。范围由实测不确定性、硬件规格与任务灵敏度确定，并检查物理相关性；不存在通用±30–50%。先辨识再随机化，防止不真实组合。

**追问 2**〔推断〕：real2sim 怎么做？资产哪来、材质光照怎么估？
**答**〔推断·工程作答〕：可用CAD、扫描或摄影测量构建场景，标定相机与关键尺度；材质和光照用测量/拟合近似。是否需要视觉高保真取决于策略输入，纯本体控制不必追求照片级纹理；验证目标是与任务相关的误差。

**追问 3**〔推断〕：举一个"仿真完美、真机因延迟震荡"类实例？
**答**〔推断·工程作答〕：这是机理假设：未建模延迟可能降低相位裕度，引起振荡。先测端到端延迟并在仿真复现，再调整带宽、补偿或训练分布；额外低通也会引入相位滞后，不能无条件当救稳方案。

**易错**：照搬随机化百分比，或在延迟振荡时无分析地额外加低通。

<details class="chain">
<summary><span class="lv lv-l3">L3</span> <span class="freq">〔推断·历史题单待核〕</span> <b>C07</b> · 腿足机器人：腿的串联/并联结构有什么区别？</summary>

**答**〔推断·工程作答〕：串联腿由关节链连接末端，结构直观但仍有动力学耦合；闭链/并联机构可降低部分运动惯量或提高刚度，也会限制工作空间并引入约束和奇异。具体性能取决于连杆、执行器布局和传动，平面两连杆本身不自动等于并联，不能按“串联/并联”标签判定力密度或稳定性。

**追问 1**〔推断〕：为什么不在训练端做 action smoothing？训练端要做得怎么做？
**答**〔推断·工程作答〕：可以在训练中平滑，但须把滤波器、状态和延迟放进环境执行链，并在部署保持一致。只在真机额外加滤波会改变策略经历的动力学；动作变化惩罚、输出参数化与执行滤波也不是同一种平滑。

**追问 2**〔推断〕：heading correction 是什么？
**答**〔推断·工程作答〕：先定义目标航向与当前航向的误差，再通过外环目标角速度、策略观测或奖励设计闭环纠偏。注意角度环绕和坐标约定；有偏航指令时不能强行锁定绝对yaw。

**追问 3**〔推断〕：陀螺仪不准怎么处理？
**答**〔推断·工程作答〕：先检查时间戳、量程、零偏、温漂与振动，再用合适的IMU模型和多源融合估计姿态。加计受线加速度、磁力计受磁干扰，不能盲信；仿真噪声模型与部署滤波应一致。

**追问 4**〔推断〕：obs/action 镜像是什么？
**答**〔推断·工程作答〕：按机器人几何和坐标约定交换左右索引，并正确处理向量/轴向量的符号与命令。只有环境与任务近似对称时才适用；不能对全部欧拉角、关节角机械乘负号。

**追问 5**〔推断〕：对称 loss 的权重怎么定？
**答**〔推断·工程作答〕：先定义镜像等变误差并校验变换本身，再扫权重看任务性能和左右偏差。非对称负载/地形可能要求非对称行为，约束过强会损任务；系数不宜脱离loss归约和量级照搬。

**追问 6**〔推断〕：腿解算指什么？
**答**〔推断·工程作答〕：通常指足端目标到关节角的IK，也可能指前向运动学，先问清接口。若策略直接输出关节目标，不一定每步再做IK；需要IK时须处理工作空间、分支、限位和奇异。

**追问 7**〔推断〕：指令映射怎么做？
**答**〔推断·工程作答〕：明确用户命令是躯干速度、航向还是姿态，再映射到策略条件、规划目标或跟踪奖励。限制命令变化率并验证不同坐标系、饱和和急停语义，不把速度命令直接当关节目标。

**追问 8**〔推断〕：为什么对输出做了滤波不影响网络？
**答**〔推断·工程作答〕：滤波会改变实际闭环，不能说“不影响”。若训练已包含滤波，部署应复现同一滤波器参数、状态更新与时序；不是在相同链路额外再串一个滤波器。用step响应和闭环性能验证一致性。

**易错**：把滤波说成不影响网络，或训练已含滤波却在部署又串联一份。

<summary><span class="lv lv-l1">L1</span> <span class="freq">〔推断·历史题单待核〕</span> <b>C08</b> · 强化学习和传统控制各自的优势？怎么选、怎么分工？</summary>

**答**〔推断·工程作答〕：常见架构让RL输出目标或残差，传统伺服实现快速反馈，也可由RL直接输出力矩；这不是硬性层级。按安全约束、可分析性、模型误差、训练数据和实时性选型。模型控制可显式处理约束，学习策略可利用复杂数据，但两者都需要闭环验证与保护，不以“RL免建模”承诺免校准或免稳定性设计。

**追问 1**〔推断〕：PID 怎么设计？
**答**〔推断·工程作答〕：先定义被控对象、量测、执行器限幅与采样/延迟；用模型或受控低能量实验整定，先保证方向与保护正确，再验证带宽、稳态误差和抗扰。加入积分要抗饱和、微分要处理噪声；真机不应无保护地推到临界振荡。

**追问 2**〔推断〕：时域 vs 频域分析，你用哪个看什么？
**答**〔推断·工程作答〕：时域看超调、稳定时间、跟踪误差与限幅；频域看带宽、增益/相位裕度及共振。两者互补，离散采样与延迟须入模型。仅用一条平滑轨迹不能证明鲁棒稳定。

**追问 3**〔推断〕：最看重的指标是什么？
**答**〔推断·工程作答〕：指标由任务风险确定：跟踪精度、扰动恢复、稳定裕度、峰值力矩、能耗或安全事件。先给约束与成功判据，再选优化指标，不把某个指标说成所有系统唯一重要的量。

**追问 4**〔推断〕：RL 给传统控制带来了什么？
**答**〔推断·工程作答〕：可学习难建模的残差、目标、增益调度或技能策略，但收益要用同预算基线与消融验证。对未知输入、接触切换和分布外场景仍需约束与降级，不能把学习层作为稳定性的免费来源。

**易错**：断言学习策略永远不能输出力矩，或在真机无保护地寻找临界振荡。

<summary><span class="lv lv-l2">L2</span> <span class="freq">〔实录主题+推断〕</span> <b>C09</b> · MPC 的原理？和 LQR、PID 比怎么选？</summary>

**答**〔推断·工程作答〕：MPC反复用当前状态求有限时域优化并执行前缀，可显式处理约束；LQR针对线性二次结构，既有有限时域也有无限时域形式；PID按误差反馈。区别不是“LQR永远离线、MPC天然稳定”，而是模型、代价、约束与求解方式。选型要核对状态估计、延迟、可行性和稳定性设计。

**追问 1**〔推断〕：MPC 实时性怎么保证？
**答**〔推断·工程作答〕：先量测最坏时延，再优化模型/时域、稀疏结构、热启动和求解器配置；线性化、代码生成或近似策略需检查误差。设置硬截止与已验证的降级，不以平均求解时间代替实时保证。

**追问 2**〔推断〕：求解失败/超时怎么办？
**答**〔推断·工程作答〕：保留最后可行轨迹可能有用，但在状态变化后未必安全；软化选定约束也不保证整体可行。应按系统风险预先验证安全控制器、制动/降级或重规划策略，监控求解状态与约束违反，不能临场随意沿用旧量。

**追问 3**〔推断〕：qpOASES 和 OSQP 怎么选？
**答**〔推断·工程作答〕：qpOASES是主动集方法，OSQP面向稀疏QP采用算子分裂；二者的热启动、精度、规模和部署条件不同。用目标问题集比较尾时延、残差和失败率，不按“机械臂一定A、腿足一定B”选。

**易错**：软化约束/沿用旧控制量就声称已保证可行与安全。

<summary><span class="lv lv-l3">L3</span> <span class="freq">〔推断·历史题单待核〕</span> <b>C10</b> · 电流环、速度环、位置环是怎么嵌套的？</summary>

**答**〔推断·工程作答〕：常见级联为位置误差生成速度目标，速度环生成电流/力矩目标，电流环驱动电压。内环通常设计得比外环带宽高，使外环能近似使用已闭合的内环；采样频率和闭环带宽不同，具体数值由驱动器、电机、负载、延迟与裕度决定，不给所有机器人套同一kHz表。

**追问 1**〔推断〕：为什么外环套内环？内环频率一定要高吗？
**答**〔推断·工程作答〕：级联把不同动态尺度分开设计。内环通常需足够快且稳定，但“更新频率更高”本身不证明带宽更高；还要看离散延迟、滤波、执行器和增益。外环设计须使用真实内环响应。

**追问 2**〔推断〕：三个 PID 先调哪个？
**答**〔推断·工程作答〕：通常先验证/整定电流环，再速度环，最后位置环；某些驱动器已有内环或不同结构，要按实际接口。每层在限流、限速与可控负载下验证，不能内环不稳还继续加外环增益。

**追问 3**〔推断〕：1kHz 控制频率、PID计算 0.2ms、执行器延迟 5ms，延迟怎么补偿？
**答**〔推断·工程作答〕：5ms是执行延迟，不等于5ms更新周期或200Hz上限；流水线可每1ms接令。分解采样、计算、通信和执行延迟，分析离散闭环裕度，再考虑预测/Smith类补偿或降低带宽。0.2ms计算也需检查抖动，不能只靠频率相除。

**追问 4**〔推断〕：传感器抖怎么滤？
**答**〔推断·工程作答〕：先判断噪声、真实振动或丢包，核对采样/抗混叠与时间戳，再选低通、陷波或状态估计。所有滤波延迟都进入闭环；不能无脑降低截止频率，须复核相位裕度和任务响应。

**追问 5**〔推断〕：卡尔曼滤波的 Q/R 怎么调？
**答**〔推断·工程作答〕：Q/R是过程和测量噪声协方差。先用模型残差、传感器数据估计量级，再检查创新均值、白性和一致性。简单可比模型下增Q更跟测量、增R更信模型，但多维相关系统不能机械逐元素推断。

**追问 6**〔推断〕：KF 和互补滤波什么时候用哪个？
**答**〔推断·工程作答〕：互补滤波适合明确的频段互补与较简单的估计；KF/EKF能显式利用状态/噪声模型做多源融合。两者都含假设，互补滤波也不一定无模型；按传感器、非线性与算力选择，不能仅凭传感器数量。

**易错**：把执行延迟5ms误当更新周期5ms，再推成200Hz上限。

**答**〔推断·工程作答〕：误差可能来自齿隙/换向滞环、加工与装配传动误差、负载弹性、摩擦、温度与磨损；电机端编码器不能完整观测输出端变形。区分精度、重复性和负载依赖误差，设计输出端测量与正反向/不同负载实验，不把末端误差全部归因减速器。

**答**〔推断·工程作答〕：比较输入端按减速比换算的位置与输出端测量，扫角度、方向、速度和负载；末端测量另受连杆与标定误差影响。报告仪器精度、同步、温度与重复次数，避免把测量噪声当传动误差。

**答**〔推断·工程作答〕：质量/质心/惯量、负载、摩擦、柔性、背隙与几何零位都可能不同。力矩残差也可能来自电流标定、同步、微分噪声和未建模接触，不唯一证明URDF参数错；先分离测量与模型误差。

**追问 3**〔推断〕：动力学参数怎么辨识？（最小二乘 + 激励轨迹）
**答**〔推断·工程作答〕：写 $\tau=Y(q,\dot q,\ddot q)\theta$，先检查可辨识基参数与激励秩，再设计受限激励、同步采样并用QR/SVD或正则最小二乘。全参数常秩亏，不能默认 $(Y^TY)^{-1}$ 存在。筛查质量、惯量三角不等式等物理一致性，并用未参与拟合的轨迹验证。

**追问 4**〔推断〕：摩擦怎么建模？
**答**〔推断·工程作答〕：先试库伦与黏性项，低速可能还需Stribeck、静摩擦/滞环；温度、负载和方向会影响参数。用受控恒速与换向实验拟合，验证不同工况，不把单条曲线外推到所有接触状态。

**答**〔推断·工程作答〕：使用独立轨迹、速度与负载比较预测力矩/跟踪残差，给误差分布与不确定性。说明自己做过的数据、回归与验证部分；能背条件数或公式并不等于做过，也不能仅凭术语流畅判断真实性。

**易错**：未查可辨识性就显式求逆正规矩阵；仅凭残差断言参数错。

**答**〔推断·工程作答〕：LADRC以线性扩张状态观测器估计总扰动并在控制律中补偿，常用观测器/控制带宽组织整定。优势依赖输入增益、相对阶、采样、噪声和未建模动态等条件，不保证全部抵消扰动或天然强解耦。与PID比较应在同限制和工况下看跟踪、抗扰、噪声敏感性及实施成本，而不是宣称一种必然更好。

**答**〔推断·工程作答〕：给出误差定义、基线、负载/轨迹/扰动、采样和重复次数，说明分母及统计不确定性。单次最好结果不能代表平均改进；同时报告峰值力矩、噪声放大或响应变慢等代价。

**追问 2**〔推断〕：和 RL 怎么结合？RL 是你做的吗？
**答**〔推断·工程作答〕：可让RL给目标/残差、LADRC做跟踪，但须分析接口带宽、饱和与分布外输出；ESO不保证兜住任意错误目标。如实说明自己实现、整定和联调的部分，不把组合框图当闭环验证。

**易错**：把ESO估扰等同任何条件下完全抵消扰动，认为可兜任意上层错误目标。

**追问 1**〔推断〕：model-free vs model-based 怎么答？
**答**〔推断·工程作答〕：model-based在决策/更新中显式利用环境模型，模型可已知也可学习；model-free不以此模型做规划/更新。仿真里跑PPO仍可是model-free，环境存在模型不改变算法类别。样本效率与稳定性取决于具体方法和问题。

**追问 2**〔推断〕：offline RL vs online RL？
**答**〔推断·工程作答〕：offline RL用固定数据集、不在训练中采新交互，需处理分布外动作与支持覆盖；online RL持续获得交互数据。可演示初始化后在线微调，BC是监督学习并非RL。真机在线试验还需预算、保护和审批，不能因有仿真就忽略gap。

**易错**：把公司风格当固定事实；以仿真有模型就把PPO归类model-based。
